# 1. Objetivos y fundamentos
DNS organiza los nombres en una estructura jerárquica.
En debian.raul.test, test es el dominio superior,
raul.test es nuestra zona y debian identifica al servidor.
El servidor será autoritativo para nuestra zona directa e inversa.
También permitirá consultas recursivas desde localhost y la red privada.
## 2. Entorno
-Sistema: Debian.
-Servidor DNS: BIND9.
-Red privada: 192.168.56.0/24.
-IP del servidor: 192.168.56.10.
-Dominio: raul.test.
-Nombre del servidor: debian.raul.test.
